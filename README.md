# muzer

An audio player in terminal.

Tired of the cumbersome experience of mainstream music players, I decided to create my own solution. :)

## Prerequsities

- Zig >= 0.17.0

- zigzag >= 0.1.2

## Build and Test

~~~bash
# build
zig build -Doptimize=ReleaseFast
# run
zig build run
~~~

## Usage

~~~bash
muzer
~~~
